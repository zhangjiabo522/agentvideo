# 映序公开作品页

## 使用范围

站点处于公开预览模式时，以独立作品页替代工作台。页面只提供视频播放、作品下载与 GitHub 源码链接。工作台通过 React.lazy 独立加载，作品页不加载其组件或样式。

## 检索依据

UI UX Pro Max 的 `video portfolio dark minimal` 设计系统检索匹配 Dark Mode (OLED) 与 Hero-Centric Design，适用于娱乐和视频展示；React 栈的 `lazy loading video` 匹配 Lazy load components。采用电影式暗色表面、突出单个可控制的视频播放器、清晰作品网格与按需加载媒体。

## 品牌取舍

沿用主设计系统的映序名称、Film 图标、中文系统字体与暗色绿色品牌令牌。检索建议的红色播放强调色替换为映序已有 `#7DD3AE`，维持工作台与作品页一致。公开页属于展示场景，使用稀疏排版而非编辑器的信息密度。

## 页面与交互

- 深色背景 `#101713`，表面 `#19221C`，主要文字 `#E6EEE9`，次要文字 `#ADBCB2`，分隔线 `#34453A`。
- 一个活动播放器使用原生 controls、playsInline、preload=none 与封面；不自动播放，不为作品网格预下载视频。
- 卡片封面或标题选择作品并聚焦播放器。卡片与播放器均提供明确下载入口。
- 只展示公开清单中的标题、描述、时长、尺寸、时间与精选标记。
- 所有控件具备键盘焦点、中文名称与至少 44px 的操作区域；尊重 reduced motion。
- 网格在桌面三列、平板两列、小屏一列；375px 不产生横向滚动。
- 加载、空清单、网络失败和视频播放失败均提供中文状态与可执行恢复动作。
