# 让 AI 使用映序剪辑视频

映序向 AI 提供视频制作工具。AI 读取当前工程，逐步安排镜头、文字、图片、图表和音频，通过校验后保存；人通过画布、时间线和执行记录实时查看结果。默认流程只需要向 AI 描述目标，需要精修时可以人工接管。

## 两种接入方式

| 方式 | 谁执行模型推理 | 如何操作映序 | 模型要求 |
| --- | --- | --- | --- |
| 工作台“AI 剪辑导演” | 已保存的文本模型服务 | 内置多轮工具运行器 | 兼容 `chat/completions`，支持标准工具调用 |
| 外部 AI 客户端 | 外部客户端选择的模型 | HTTP MCP 服务 | 客户端和模型具备 MCP 工具操作能力 |

生图与配音工具读取映序已保存的供应商配置。外部客户端的文本模型配置与映序文本模型配置相互独立；已有工程预览和渲染不需要文本模型参与。

## 内置 AI

启动映序，在模型设置中保存文本服务地址、模型名称和密钥。普通对话连接测试只能证明接口连通，不能替代工具调用能力验收。

在“AI 剪辑导演”中输入：

> 制作一支 30 秒的映序宣传片，说明 AI 自动编排镜头、实时观察、图片和旁白接入。请直接调用剪辑工具制作，加入中文旁白，检查画面并导出视频。

提交前工作台先保存当前工程。后台任务依次读取工程、规划、调用工具、处理错误，再提交有效结果。默认观看模式展示每次修改和预览位置；请求宣传片、成片或导出时，运行器要求提交视频导出后才结束。

内置任务上限为 20 轮模型请求、40 次工具调用、15 分钟。同一工程同时只能运行一个内置任务。点击停止会取消后续模型和工具调用，保留已经保存的剪辑；导出一旦提交，需在导出任务中单独取消。服务重启不会继续显示假运行，而会把中断任务标记为失败。

## 外部 AI 与 MCP

服务地址为 `http://127.0.0.1:8080/mcp`，选择 HTTP 连接。映序服务和客户端需要运行在能访问同一本机地址的环境；容器或远程机器里的 `127.0.0.1` 指向其自身，不能直接代表映序所在机器。当前端点限制本机请求，远程部署和鉴权暂未实现。

在支持 `mcpServers` 与 HTTP `url` 的客户端中使用下列配置。可直接参考文件 [mcp-config.json](mcp-config.json)；不同客户端若要求不同字段，按它的 HTTP MCP 格式填写相同地址。

```json
{
  "mcpServers": {
    "yingxu": {
      "url": "http://127.0.0.1:8080/mcp"
    }
  }
}
```

在映序“连接外部 AI”窗口查看当前工程编号，把编号交给外部 AI：

> 使用映序 MCP 工具编辑工程“这里填当前工程编号”。先调用 `video_project_get` 读取工程和最新版本，按镜头逐步制作一支 30 秒宣传片。调用真实配音或生图工具时使用返回素材，不要编造地址。每步检查错误并修正，最终定位预览、提交 MP4 导出，返回导出任务编号。

MCP 使用无状态 HTTP JSON-RPC 请求。当前支持初始化、工具列表、工具调用和存活检查；工具结果同时提供文本和结构化数据。`GET /mcp` 返回不支持，实时更新由独立工程事件流提供。外部 AI 不受内置任务的 20 轮限制，调用次数和停止需由外部客户端管理。

## 工具目录

| 工具 | 用途与主要参数 |
| --- | --- |
| `video_project_list` | 列出已保存工程；外部 AI 可定位工程 |
| `video_project_get` | 读取工程、镜头、图层、音频及最新 `revision`；参数 `projectId` |
| `video_project_create` | 新建工程；可提供名称和规格或完整合法工程；用于外部 AI |
| `video_edit` | 原子编辑批次；参数 `projectId`、`revision`、`operations` |
| `video_undo` | 撤销最近 AI 剪辑批次；参数 `projectId`、`revision`，当前服务保留最近 50 步 |
| `video_speech_generate` | 真正合成并自动加入旁白；参数 `projectId`、`text`，可覆盖音色、语速、起点等 |
| `video_image_generate` | 真正生图并放到指定镜头底层；参数 `projectId`、`prompt`、可选 `sceneId` |
| `video_preview` | 定位人的预览，并真实渲染指定帧 PNG；参数 `projectId`、`frame`，MCP 可选 `includeImage` |
| `video_export` | 导出最新保存工程；参数 `projectId`，返回 `job.id` |
| `video_export_status` | 查询进度、状态与完成后的下载地址；参数 `jobId` |

工具参数的最终依据是服务端 `tools/list` 或 `GET /api/tools`。内置 AI 不提供跨工程列表和创建工具，并限制所有操作只能针对任务绑定工程；导出查询只能访问该任务产生的导出编号。

`video_preview` 返回工程结构、预览地址和 `screenshot`，截图信息含素材地址、本机路径、类型与尺寸。MCP 调用设置 `includeImage: true` 时可以附加 PNG 图片内容供具有视觉能力的模型读取；纯文本模型使用结构和截图链接，不能宣称已经理解图片中的视觉细节。截图真实渲染仍需可用浏览器和渲染服务，失败返回具体错误。

`video_edit` 支持工程更新、镜头新增更新删除与排序、图层新增更新删除、音频新增更新删除。镜头 `duration` 以整数帧计；图层 `start`、`end` 是镜头局部帧；音频 `start` 是工程全局帧，`trimStart` 与 `duration` 表示源素材裁剪位置和长度。所有时间以工程 `fps` 换算。

## HTTP 调用与事件

不使用 MCP 时也可以直接调用 `POST /api/tools/call`：

```json
{
  "name": "video_project_get",
  "arguments": {
    "projectId": "当前工程编号"
  }
}
```

读取到工程最新版本后，可提交局部剪辑批次：

```json
{
  "name": "video_edit",
  "arguments": {
    "projectId": "当前工程编号",
    "revision": 1,
    "operations": [
      {
        "type": "node.update",
        "sceneId": "目标镜头编号",
        "nodeId": "目标标题编号",
        "patch": {
          "text": "让 AI 剪辑，让创意成为画面"
        }
      }
    ]
  }
}
```

示例编号和版本必须替换为实际读取结果。一次批次只有全部校验成功才保存；冲突或非法属性不会部分提交。版本冲突后重新读取工程，依据最新状态修改，不自动覆盖他人的提交。锁定图层和 `protected` 手动属性始终接受保护校验。

实时接口为 `GET /api/projects/{id}/events`，浏览器以 SSE 接收工程快照、工程更新、预览定位和任务步骤。事件编号支持 `Last-Event-ID` 或 `after` 续接，连接时同步当前工程；最近事件缓冲与 AI 撤销快照在内存中，不能当作持久版本历史。任务记录和工程文件持久保存，`GET /api/projects/{id}/activity` 提供当前服务中的最近活动。

## 观看、接管与主题

默认观看时，人的画布操作不会更改工程；播放、定位和查看仍可进行。点击“人工接管”后开启手动编辑，返回观看后继续观察 AI 操作。内置任务运行期间需要先停止；外部 AI 必须在它自己的客户端停止，工作台接管按钮无法强制终止外部客户端。

顶部主题按钮切换暗色和亮色，选择保存在当前浏览器，首次使用跟随系统。主题只影响工作台，不改变视频工程中的背景、文字、素材和导出颜色。

## 验收状态

内置运行器的模拟多轮工具调用、校验失败修正、实际工程保存与事件发布、取消网络请求、范围限制、任务与工具上限、重启中断、宣传片导出提交已通过竞态测试。

外部 MCP 客户端真实连接、预览截图与可选图片回传、新版观看与接管界面、断线重连、暗色模式和真实已配置模型制作宣传片待端到端验收。模型完成文字说明、工具返回导出任务和最终视频渲染完成是三个不同状态；只有导出任务 `completed` 且实际视频可播放，才说明已得到成片。远程生图与配音的模拟协议测试不代表所有供应商真实效果已验证。
