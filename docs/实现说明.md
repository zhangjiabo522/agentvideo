# 映序当前实现说明

## 当前形态

映序采用 Go 后端、React + Vite 前端，同源运行。AI 是剪辑工具的操作者：外部 AI 通过 HTTP MCP 调用工具，内置 AI 通过标准多轮工具调用读取工程、编辑镜头与图层、安排音频、获取素材和提交导出。浏览器默认供人实时观看过程；人工接管后可直接调整画布、属性和时间线。

每次有效剪辑通过校验后立即保存，服务端事件流把工程、预览位置和执行记录推送给工作台。导出使用同一套场景组件，通过 Playwright 逐帧渲染，再用 ffmpeg 编码为 H.264 MP4。旁白和音乐混合为 AAC 音轨，整个过程不依赖视频生成模型。

工程包含画布尺寸、帧率、场景、图层、动画、音频和修订号。保存采用本地恢复草稿及服务端工程文件；服务端通过修订号拒绝覆盖已经更新的工程。所有 AI 工具共用校验，遵守锁定图层和手动属性保护。保留的旧单次工程生成接口用于兼容，默认流程已切换为多步工具执行。

## 已实现功能

- 画面：文字、图片、矩形、圆形、柱状图；画布选中、拖动、尺寸调整及属性编辑；图片填充与完整显示。
- 镜头：新建、复制、删除、排序、时长调整；工程比例支持 16:9、9:16、1:1。
- 时间线：镜头排序与开始或结束裁剪、图层时间片段移动与裁剪、音频位置移动与素材裁剪；支持对应属性输入和键盘调整。
- 音频：上传旁白或音乐、音量、起点、素材起点、时长、淡入和淡出；预览和导出使用同一份音轨参数。
- 旁白：本地默认普通话、小米 MiMo、OpenAI 兼容协议；人工入口可先试听再添加，AI 工具直接合成并加入音轨，必要时延长末镜头。真实音频文件参与导出。
- 模型设置：文本、生图、语音三类配置；远程模型列表刷新与选择，同时保留手动输入模型名；设置密钥不会在读取时回显。
- 素材库：服务端读取实际图片和音频，持久保存名称、来源、尺寸或时长；已有文件可发现，上传、生图、配音和工程包导入统一登记。前端提供真实缩略图、搜索、类型筛选、已使用标记与失败重试。
- AI 工具：读取工程、原子剪辑批次、撤销、生图并放置图片、合成并放置旁白、定位预览、导出和导出状态查询。MCP、HTTP 工具接口和内置 Agent 调用同一实现。
- 内置 Agent：每次任务只操作指定工程，最多 20 轮模型调用、40 次工具调用、15 分钟；工具错误回传模型修正；任务取消中断后续步骤并保留已提交结果；同一工程的重复内置任务返回冲突。
- 观察与接管：默认实时观看，画布和时间线响应服务端工程更新；需要人工编辑时切换接管，内置任务进行中需先停止。开始 AI 任务前保存人工修改。
- 主题：顶部按钮切换亮色和暗色，浏览器记忆选择，首次使用跟随系统。主题作用于工作台，不进入渲染画面。
- 导出与工程迁移：异步 MP4 导出、进度、取消、完成下载；只读 JSON 查看与下载；完整 ZIP 工程包下载和导入，下载提交当前工程快照，不依赖先保存。
- 弹窗：Escape 关闭、点击遮罩关闭、焦点循环和恢复、中文错误反馈、新建或打包失败直接在弹窗内展示。

## 接口约定

外部 AI 接入 `POST /mcp`，采用 HTTP JSON-RPC MCP：支持 `initialize`、`ping`、`tools/list` 和 `tools/call`，返回结构化工具结果和中文错误。端点为无状态请求，不提供独立 MCP 事件流；实时工程事件使用下述 SSE 接口。当前检查本机主机名与浏览器同源请求，完整工作台没有登录或访问鉴权，默认只监听本机。服务器上的私人工作台使用 SSH 隧道访问，不能将主机名检查当作公网权限系统。完整流程见 [AI 接入说明](AI接入.md)，配置见 [MCP 示例](mcp-config.json)。

HTTP 工具目录为 `GET /api/tools`，调用为 `POST /api/tools/call`，请求 `{name, arguments}`。`video_edit` 使用 `{projectId, revision, operations}`，每批校验成功才递增版本并保存；错误时整批不应用。冲突必须先重新调用 `video_project_get` 取得最新版本，当前不做对象级自动合并。

素材列表使用 `GET /api/assets`，支持 `query`、`type`、`source` 与 `projectId` 查询参数，响应为 `{assets: [...]}`；其中 `projectId` 按素材被工程引用的关系过滤。`video_assets_list` 为 AI 返回可复用的工作区素材，包含真实 URL、名称、类型、大小、图片尺寸或音频时长、来源和引用工程。素材目录保存在数据目录中的 `assets.json`，刷新列表会校对实际文件；不返回临时文件与新生成的工程预览截图。旧文件没有来源记录时按已有素材发现。新增素材通过 `assets.updated` 事件通知已连接的工作台。

内置任务使用 `POST /api/agent/runs`，请求 `{projectId, prompt}`，成功返回 HTTP 202 与 `{run}`。查询使用 `GET /api/agent/runs/:id`、`GET /api/projects/:id/runs`，停止使用 `POST /api/agent/runs/:id/cancel`。状态为 `queued`、`running`、`completed`、`failed`、`cancelled`。任务记录持久保存；服务重启把未结束任务标记为中断失败，保留已经保存的工程。宣传片、成片或导出要求在结束前必须提交导出任务；提交后任务结束，由界面查询渲染状态。

实时观看使用 `GET /api/projects/:id/events`，浏览器通过 `EventSource` 接收工程快照、`project.updated`、`preview.seek`、`run` 和导出事件。事件包含 `seq`、`type`、`projectId`、`message`，可携带 `project`、`runId`、`tool`、`data`；内置运行状态置于 `data.run`。重连可携带 `Last-Event-ID` 或 `after`，并再次收到当前工程快照。最近活动使用 `GET /api/projects/:id/activity`；活动和事件缓冲在内存中，服务重启后不承诺完整重放历史。

`video_preview` 同时定位工作台与真实渲染指定帧 PNG，返回 `screenshot` 的地址、本机路径、类型和尺寸。MCP 参数 `includeImage: true` 可把 PNG 内容附加到工具响应，供支持视觉的外部模型读取；纯文本模型仍使用结构与截图链接，不具备自动理解画面内容的能力。

模型设置使用 `GET /api/settings`、`PUT /api/settings`、`POST /api/settings/test`。模型列表使用 `POST /api/models`，请求包含当前设置和 `kind`（`text`、`image` 或 `tts`），响应为 `models: [{id, name?}]`。刷新列表不会直接覆盖已有模型名；接口不支持列表时可以继续手动输入。

语音设置包含 `ttsProvider`、`ttsBaseUrl`、`ttsModel`、`ttsApiKey`、`hasTtsApiKey`、`ttsVoice` 和 `ttsSpeed`。本地默认来源为 `local`、音色 `cmn`；MiMo 预置地址 `https://api.xiaomimimo.com/v1`、模型 `mimo-v2.5-tts`、音色 `mimo_default`；兼容来源允许填写服务地址、模型和音色。

导出使用 `POST /api/exports`，请求为 `{project}`。界面定期查询 `GET /api/exports/:id`，并使用 `POST /api/exports/:id/cancel` 取消任务。任务状态为 `queued`、`running`、`completed`、`failed`、`cancelled`；`progress` 为 0 到 1 的比例值，界面显示百分比。完整工程包使用 `POST /api/bundle`，请求为 `{project}`，响应为 ZIP。

## 验证方式与证据范围

仓库提供下面几类验证，结果用于确认相应功能，不能推定尚未连接的供应商或客户端已经兼容：

| 验证 | 范围 |
| --- | --- |
| `go test -race ./...` | 后端接口、工程校验、保存、工具原子性、模型协议、任务状态和并发行为 |
| `go vet ./...` | Go 静态检查 |
| `npm run build` | TypeScript 检查与前端生产构建 |
| `npm run test:browser` | 桌面和窄屏编辑器、保存、撤销重做、时间线、模型表单、弹窗与工程迁移 |
| `npm run test:export` | 临时服务真实导出，验证动画帧、镜头边界、图片加载、静止帧复用、音频裁剪混合、取消与异常清理 |

浏览器与导出报告保存在本机 `test-results`。导出验收已覆盖视频帧数、分辨率、帧率、音轨与时长，并通过实际解码检查画面和音频；不能仅根据接口返回 200 判断成片成功。导出脚本需要 Go、Node.js、FFmpeg、FFprobe 与 Chromium。

本机 MCP 的 HTTP JSON-RPC 实测覆盖初始化、工具列表、工程读取、实际 PNG 截图和图片回传，以及非法编辑不改变工程版本和内容。该实测使用 HTTP 客户端，不代表具体品牌的 MCP 客户端已全部连接验证。

内置 Agent 模拟测试覆盖多轮读取和编辑、错误回传与修复、无工具文字响应拒绝、取消模型网络请求、工程范围限制、任务和工具调用上限、重启中断，以及要求成片时提交导出。模拟测试不消耗远程模型费用；远程图片与语音效果仍需用对应供应商配置实际确认。

产品交付应同时检查最终 MP4 可播放、内容正确、音画时长合理，以及真实工作台中的实时更新和素材显示。界面主题与观看体验需要浏览器检查，不能只凭生产构建通过得出结论。

## 当前边界

当前是 AI 可操作、供人实时观察的信息类短视频制作首版。工程最多 20 个镜头、300 个图层、120 秒；视频导出画布最大为 1920 像素，最多 12 条音轨。标准场景仅支持已定义的对象和动画，不运行任意模型生成代码。

内置模型必须支持标准工具调用，没有把文字或完整工程 JSON 静默转换成工具执行的兼容机制。MCP 客户端需支持 HTTP 地址配置；不同客户端的配置格式和协议兼容性要实际确认。人工接管只控制本工作台的手动编辑，不能强制停止另一个外部 AI 客户端；外部 AI 需在它自己的客户端停止。已经提交的导出任务与 AI 剪辑任务分别取消。

复杂代码组件、完整专业剪辑流程、任意代码自动拆分为可编辑图层、字幕自动识别与对齐、多轨视频素材剪辑、真实人物连续动作和三维场景尚未完成。文本图层可以承载字幕内容，不能将其等同于完整字幕生产功能。生图输出为静态图片，图片平移、缩放和裁剪不等同于视频生成。
